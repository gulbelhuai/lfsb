# 补贴发放记录（只读，数据源=财务通过的支付计划明细）

## 口径

与「居民查询 → 补贴发放记录」一致：

- 表：`shebao_payment_plan_detail` + `shebao_payment_plan`
- 条件：计划未删、明细未删、`finance_status = finance_approved`
- 派生状态：计划未 `completed` → 发放中；明细 `failed` → 发放失败；否则已发放

## API

| 方法 | 路径 | 权限 |
|------|------|------|
| GET | `/shebao/distribution/record/list` | `shebao:distribution:record:list` |
| POST | `/shebao/distribution/record/export` | `shebao:distribution:record:export` |

查询条件：业务期、发放类型(normal/second)、补贴类型、发放机构、身份证、姓名、批次号、发放状态。
