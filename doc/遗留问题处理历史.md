### ISS-014 发放记录双菜单 / finance_rejected → 核实关闭（非问题）

| 项 | 内容 |
|----|------|
| **原关注** | 「补贴发放记录」与「发放明细」同页；`finance_rejected` 出现在审批/财务两字段易混 |
| **核实结论** | 这两处功能**都不展示** `approval_status` / `finance_status`。查询强制 `finance_status = finance_approved`，列表/导出只有派生 **发放状态**（发放中 / 已发放 / 发放失败）。用户在这两页看不到「财务驳回」。双菜单是补贴发放 vs 统计管理入口共用只读页，属有意设计，不是审核态展示冲突。 |
| **证据** | `distribution/record/index.vue`；`PaymentPlanDetailMapper.selectDistributionRecordList`；`doc/补贴发放记录查询.md` |
| **说明** | 支付计划生成/审核/财务页仍可能同时出现 `finance_rejected` 文案，那是支付计划侧展示问题，与发放记录查询无关，不单列为本条。 |
