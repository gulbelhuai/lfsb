# 居民查询：预发放与发放记录（支付计划明细）

> 记录时间：2026-08-01  
> 页面：`/assign/residentQuery`

## 口径

| 模块 | 数据源 | 过滤 |
|------|--------|------|
| 预发放记录 | `shebao_payment_plan_detail` + 计划主表 | `del_flag=0`，`subsidy_person_id` 匹配，计划未删，且 `finance_status` 为空或 ≠ `finance_approved`；不展示发放状态 |
| 补贴发放记录 | 同上 | 计划 `finance_status = finance_approved` |

发放状态（仅发放记录）：

- 计划未完成银行流程 → **发放中**
- 计划已完成且明细 `failed` → **发放失败**（展示失败原因）
- 计划已完成且非失败 → **已发放**

发放日期：财务通过时写入明细 `distribution_date`；存量用审核流水/计划时间回填。

人员匹配：明细 `subsidy_person_id`（生成时从核定带出；存量 SQL 回填）。
